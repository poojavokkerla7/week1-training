# Week 1 Training - Gen2soft

## Overview
This repository contains solutions to core Data Structures and Algorithms (DSA) problems along with a Python-based CRUD console application. The goal of this project is to strengthen problem-solving skills and implement clean coding practices.

## Technology
- Python
- GitHub

## Work Completed
- Solved 10 DSA problems covering:
  - Arrays (Two Sum, Product Except Self, Max Subarray, Merge Intervals)
  - Strings (Valid Palindrome, Longest Substring, Reverse String)
  - HashMaps (Group Anagrams, Valid Anagram, Subarray Sum K)
- Developed a CRUD-based Student Management System

## Features
- Add student
- View students
- Delete student
- Search student

## Folder Structure
- dsa/
  - arrays/
  - strings/
  - hashmap/
- crud-app/

## How to Run
Navigate to the crud-app folder and run:
python main.py
